# Dialogue sources

Original French wording is retained in both interface languages. The remaining mission instructions and reactions are authored for the game.

- Giscard, "Vous n'avez pas le monopole du cœur": [INA, 1974 debate](https://www.ina.fr/ina-eclaire-actu/video/s1142746_001/vous-n-avez-pas-le-monopole-du-coeur). Used when starting the core mission.
- Giscard, "Au revoir": [INA, final address](https://www.ina.fr/ina-eclaire-actu/1981-valery-giscard-d-estaing-dit-au-revoir-aux-francais). Used on task departure, grid failure and the ending.
- De Gaulle, "Je vous ai compris": [Archives nationales](https://www.archives-nationales.culture.gouv.fr/dossiers-thematiques/charles-de-gaulle). Used during water-circuit recovery.
- De Gaulle, "La réforme, oui. La chienlit, non": [INA](https://www.ina.fr/ina-eclaire-actu/chienlit-charles-de-gaulle-expression-politique). Used on a broken water circuit.
- De Gaulle, "Vive le Québec libre": [INA, Montréal](https://fresques.ina.fr/de-gaulle/fiche-media/Gaulle00135/voyage-a-montreal.html). Used after Concorde lands in Montréal.
